# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии —
[SemVer](https://semver.org/lang/ru/).

## [1.0.0] - 2026-10-19

Первый релиз.

### Добавлено

- Режимы игры: классика, блиц, на время, выживание; автоматическая пауза
  таймеров после ответа.
- Статистика, XP и уровни, достижения (хранятся локально, с миграциями и
  Zod-валидацией).
- Два live-провайдера вопросов (QuizAPI, The Trivia API) и mock-провайдер;
  явное переключение провайдеров (настройки, диалог ошибки на `/quiz`,
  авто-переключение с тостом на `/setup`).
- NestJS-прокси (`server/`): ключ API живёт только на сервере, типизированный
  конверт ошибок, кэш каталога, троттлинг.
- Локализация en/ru, светлая и тёмная темы, анимации, адаптивная вёрстка.
- Главная: hero-кнопка, кольцо XP, плитки серии и сессий, «повторить
  последнюю»; панель серии в квизе.
- Футер всегда указывает обе атрибуции: QuizAPI и The Trivia API
  (CC BY-NC 4.0).
- CI/CD: lint, typecheck, unit- и e2e-тесты, деплой на Vercel.
- Лицензия MIT (данные The Trivia API — CC BY-NC 4.0, см. `LICENSE`).

### Известные ограничения

- Кэш каталога и rate limit живут в памяти экземпляра, а не глобально.
- Политика повторных ручных переключений провайдеров при отказе обоих не
  определена (см. `PLAN.md`).
